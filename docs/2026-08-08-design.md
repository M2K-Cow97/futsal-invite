# futsal-invite 코딩 기획안

목업(`기획-목업-전체.png`) 기반 구현 설계. 5개 화면을 순차 전환하는 단일 정적 페이지.

## 스택 & 배포

- Vanilla HTML/CSS/JS, 빌드 도구 없음 (index.html 하나로 동작)
- 이미지 저장: `html2canvas` (CDN script 태그로 로드)
- 배포: GitHub Pages (`M2K-Cow97/toy_project` 레포, `futsal-invite/` 서브폴더 또는 별도 배포용 브랜치는 착수 시 결정)
- 모바일 우선 반응형, 데스크톱은 중앙 정렬 카드형

## 파일 구조

```
futsal-invite/
  index.html
  style.css
  script.js
  assets/
    siu.gif            (사용자 제공)
    siu-sound.mp3       (사용자 제공)
    ronaldo-warn.png    (사용자 제공, 포지션 팝업①)
    ronaldo-stern.png   (사용자 제공, 포지션 팝업②)
  docs/
    기획-목업-전체.png
    2026-08-08-design.md
```

에셋 미제공 시 이모지/플레이스홀더 박스로 대체해 동작에는 지장 없게 한다.

## 화면 전환 구조

`<section data-screen="invite|siuuu|matchday|position|ticket">` 5개를 한 HTML에 두고, JS 상태 하나(`currentScreen`)로 `display` 토글. 뒤로가기 없음(포지션 팝업 "돌아가기" 제외), 앞으로만 진행.

상태 객체:
```js
state = { date: null, time: null, venue: '', position: null }
```
`ticket` 화면은 이 state를 그대로 렌더링.

## 화면별 동작

**① invite** — "싫어." 버튼: `mouseenter`(터치는 `touchstart`)에 호날두 킥 애니메이션(CSS keyframes) 실행 후 버튼을 컨테이너 내 랜덤 좌표로 재배치. 클릭은 걸리지 않게 `pointer-events` 타이밍 조정. 시도 횟수 카운트, 3회부터 버튼 텍스트 "포기해."로 변경. "좋아!" 클릭 시 `siuuu` 화면 전환 + 이 클릭 이벤트 안에서 `Audio` 재생(자동재생 제한 회피).

**② siuuu** — GIF/사운드 재생, "날짜 고르기" 클릭 시 `matchday` 전환.

**③ matchday** — `<input type="date">`, `<input type="time">`, 구장 `<input type="text">`. 세 값 모두 입력 전엔 "다음" 버튼 `disabled`. 미입력 클릭 시도 시 안내 문구(버튼 비활성으로 사실상 불필요하나 포커스 유도 문구 추가).

**④ position** — 4개 버튼. 미드필더/수비수/골키퍼는 클릭 즉시 `position` 저장 후 `ticket` 전환. 공격수는 팝업① 오픈("그래도 할래" → 팝업②, "안할께.." → 팝업 닫기) → 팝업②는 "돌아가기"만 있고 클릭 시 팝업 닫힘(포지션 미확정 상태 유지, 화면 전환 없음).

**⑤ ticket** — state 값을 카드에 렌더링. "이미지 저장" 클릭 시 `html2canvas(ticketEl)` → PNG 다운로드. "다시 풋살 약속잡기" 클릭 시 state 초기화 + `invite` 화면으로 복귀.

## 에러 처리 범위

폼 검증(필수 3필드)과 에셋 로드 실패 시 대체 표시 정도만 다룬다. 그 외 예외 처리는 불필요(개인용 장난 페이지, 외부 입력/보안 이슈 없음).

## 테스트

자동화 테스트 없음. 헤드리스 브라우저로 5개 화면 전체 흐름 스크린샷 확인 + 실기기(모바일 사파리) 1회 수동 확인으로 검증한다.
