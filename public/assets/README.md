이미지는 이모지 플레이스홀더로, 사운드는 무음으로 대체됩니다.

## 규격

- **이미지**: 가로 800px 내외로 충분. 큰 파일은 로딩만 느려진다.
  `object-fit: contain` 이라 잘리지 않지만, **정사각형에 가까울수록** 여백이 적다.
  인물은 얼굴이 중앙에 오게 크롭해두면 가장 잘 보인다.
- **사운드**: 2~3초 이내. `kick.mp3` 는 0.5초 이내 짧은 효과음이 좋다.

## 주의

저작권이 있는 이미지·영상·음원을 공개 배포하지 마세요. 이 앱은 공개 URL
(vercel.app)로 배포되므로, 직접 만든 에셋이나 라이선스가 허용된 소재를 쓰는 것이
안전합니다.
